# 찰칵 그림책 (가칭) 웹앱 기획서 v1.1

> v1.1에서 고친 것: **'선생님께 제출' 기능을 기본 기능으로** — 완성 MP4를 Supabase에 올려 교사 화면(제출함)에서 모아 보기·연속 재생·내려받기. 학생 원본 사진·영상은 계속 태블릿 안에만.

> 단군신화 앱의 '장면 → 그림책 완성' 흐름을 살려, 학생이 찍은 **사진·영상으로 움직이는 그림책(MP4)**을 만드는 앱. 여러 이야기를 템플릿으로 바꿔 끼워 씀. 첫 수업 적용: **유초이음 – 유치원 동생 질문에 답하는 학교생활 영상**

## 1. 한눈에 보기
- **무엇을**: 교사가 '이야기 템플릿(장·카드)'을 만들어 방에 올리면, 학생이 자기 태블릿으로 들어와 카드마다 사진·영상을 찍어 넣고, 움직임·목소리를 더해 **MP4 그림책 영상**으로 만들어 **선생님께 제출**
- **누구와**: 특수교육대상 초등 학생 (상·중·하 수준별 진행)
- **기기**: 학생 **1인 1대 갤럭시 탭**(가로), 교사는 전자칠판·PC
- **핵심 원칙**: 서버에는 **템플릿 + 완성 MP4만**. 촬영 원본 사진·영상은 **각 태블릿 안에만**

## 2. 전체 흐름
```
첫 화면
 ├─ [선생님] 방 만들기 → 교사 모드
 │     ├ 템플릿 만들기/고르기 (장·카드·여는 영상)
 │     ├ 학생 명단 + 학생별 수준(상·중·하)
 │     ├ QR·숫자코드 띄우기
 │     └ 제출함 (모아 보기·연속 재생·내려받기)
 ├─ [학생] 방 들어가기 (QR / 숫자 6자리) → 내 이름 고르기
 │     └ ① 카드 보기 → ② 촬영 → ③ 연결·꾸미기 → ④ 인사 → ⑤ 미리보기 → ⑥ 선생님께 제출
 └─ [혼자 하기] 기본 템플릿으로 방 없이 만들기 (MP4 저장만)
```
- 좌측 상단: 전체화면 / 우측 상단: 교사 모드
- 하단: `© 2026 특수교사 은티 · @special_eun_t` (인스타 주소는 첫 화면에서만 클릭)

## 3. 방·템플릿 공유 (Supabase)
- 마음방과 같은 방식: 방 만들기 → 6자리 코드 + QR, 교사 권한은 쿠키 + 4자리 PIN 백업
- 학생은 QR/코드로 입장 → 명단에서 이름 버튼 고르기(사진/그림 표시 가능)
- 템플릿 수정 시 학생 태블릿에 바로 반영
- 템플릿 **복제·내보내기(파일)** → 다른 반·다른 선생님과 나누기

## 4. 템플릿 구조
```
템플릿 (예: 유치원 동생에게 보내는 학교생활)
 ├ 여는 장면: 교사가 넣은 영상/사진 (예: 동생들의 질문 편지 영상)
 ├ 장 1. 등교
 │   ├ 카드: "휠체어를 타고 교실까지 어떻게 가나요?"
 │   └ 카드: "교실에 도착하면 제일 먼저 무엇을 하나요?"
 ├ 장 2. 식사
 │   ├ 카드: "숟가락 잘 드는 방법이 있나요?"
 │   └ 카드: "밥 먹을 때 어떤 연습을 해야 하나요?"
 ├ 장 3. 하교
 │   ├ 카드: "학교가 끝나면 어디로 가나요?"
 │   └ 카드: "몸이 힘들거나 졸리면 어떻게 알려줘야 하나요?"
 └ 닫는 장면: 학생 인사 + 엔딩 크레딧
```
### 카드마다 교사가 정하는 것
| 항목 | 내용 |
|---|---|
| 글 | 질문이나 이야기 문장 |
| 🔊 읽어 주기 | 교사 녹음 또는 자동 읽기(TTS) |
| 넣을 것 | 사진 / 영상 / 둘 다 |
| 장소 힌트 | 현관·교실·급식실·엘리베이터 등 그림 아이콘 (하 수준에게만 보이게 가능) |
| 단어 카드 | 중 수준용 답 단어 3~6개 (예: 휠체어, 엘리베이터, 손 씻기) |

- 여는 장면 영상은 **파일 업로드**로 넣음 (유튜브 링크는 MP4에 합칠 수 없음)
- 다른 이야기 예: 단군신화(하늘 → 동굴 → 나라 세우기), 현장체험학습 기억책, 주말 이야기

## 5. 학생 화면 (수업 단계별)
### ① 카드 보기 (활동1)
- 여는 영상 재생 → 카드 한 장씩 넘기기, 🔊 듣기
### ② 촬영 모드 (활동2)
- 이동 중 쓰는 화면이라 **아주 단순하게**: 위에 지금 카드, 아래에 큰 📷 사진 / 🎥 영상 버튼
- 영상은 카드당 **최대 10초**(자동 멈춤, 남은 시간 표시)
- 찍은 것은 '내 사진함'에 쌓임, 다시 찍기 가능
- 카드 넘기기 ◀ ▶ (순서 상관없이 찍기 가능)
### ③ 연결하기 + 꾸미기 (활동3)
| 수준 | 연결 방식 | 답하기 |
|---|---|---|
| 상 | 사진함에서 골라 카드 칸에 끌어 놓기 | 🎤 내 말로 답 녹음 (또는 글) |
| 중 | 끌어 놓기 (끌기 어려우면 탭) | 단어 카드 고르기 → 자막으로 표시 |
| 하 | 촬영 때 이미 연결됨 → 자동 완성 | 선택: 🎤 한 마디 |

- **얼굴 쏙**: 사진에서 얼굴만 동그랗게 잘라 그림 캐릭터 몸에 붙이기 (선택)
- **움직임 버튼**: 통통 튀기 · 걸어 들어오기 · 반짝 나타나기 · 흔들흔들 · 천천히 확대(켄 번스)
- 장면 길이: 녹음/영상 길이에 맞춰 자동, 사진만 있으면 기본 4초
### ④ 인사 (마무리)
- "동생에게 하고 싶은 말" 🎥 영상 또는 🎤 녹음
- 엔딩 크레딧 자동: "만든 사람: 초4-2 ○○", 출연 사진 모음, 저작권 표시
### ⑤ 미리보기
- ▶ 그림책처럼 넘기며 재생 (책장 넘김 효과)
### ⑥ 선생님께 제출
- 큰 버튼 하나: **📤 선생님께 보내기** → MP4 만들기(진행 막대) → 자동 업로드 → "선생님께 보냈어요!" 화면
- 업로드가 끊기면 태블릿에 남겨 두고 [다시 보내기] (와이파이 불안정 대비)
- 다시 고쳐서 보내면 **새 영상으로 바꿔치기** (학생당 1개 유지, 교사 설정으로 여러 개 허용 가능)
- 💾 내 태블릿에 저장(MP4)은 보조 버튼

## 6. 제출함 (교사)
- 학생 이름 카드 목록: **제출함 ✅ / 아직 ⬜ / 보내는 중 ⏳** 실시간 표시 (Supabase Realtime)
- 카드 누르면 크게 재생
- **연속 재생**: 제출한 영상을 순서대로 이어서 재생 → 전자칠판 발표 시간에 사용 (순서 끌어서 바꾸기)
- **내려받기**: 하나씩 / 전체 ZIP → 유치원 선생님께 전달
- 삭제: 하나씩·여러 개 선택, 확인 창
- **저장 공간 막대**: 방이 쓰는 용량 표시
- 보관 기간: 기본 **30일 뒤 자동 삭제** (교사가 7일 / 30일 / 직접 지울 때까지 중 선택). 삭제 3일 전 제출함에 안내
- 미러링 발표도 그대로 가능 (학생 태블릿 → 전자칠판)

## 7. 교사 모드
- 템플릿 편집: 장·카드 추가/삭제/순서, 카드 항목(4장 표), 여는 장면 업로드
- 기본 템플릿 제공: 유초이음 학교생활, 단군신화, 현장체험학습, 주말 이야기
- 학생 명단(CSV/붙여넣기) + 학생별 수준(상·중·하)
- 방 열기/닫기, 방 복제, 방 지우기(PIN 확인)
- 제출함 (6장)

## 8. 기술 구성
- **리액트 + Supabase + Vercel**
  - DB: rooms, students(이름·수준), templates(장·카드 JSON), submissions(학생·파일 경로·길이·크기·제출 시각)
  - Storage
    - 공개 가능: 교사가 올린 장소 아이콘·카드 녹음
    - **비공개 버킷**: 여는 영상, 학생 제출 MP4 → 교사 열쇠가 있을 때만 서명된 주소(잠깐만 열리는 링크)로 재생
  - Realtime: 제출함 상태 실시간 갱신
- 학생 작업 저장: 태블릿 브라우저 **IndexedDB** → 새로고침·화면 꺼짐에도 작업 유지
- 촬영: `<input capture>` 또는 카메라 API, 영상 10초 제한
- **MP4 만들기**: 캔버스에 장면을 그려 재생 + 녹음·영상 소리 합치기(Web Audio) → MediaRecorder로 녹화
  - 저장에 **영상 길이만큼 시간**이 걸림 (2분 영상 → 약 2분, 진행 막대 표시)
  - 개발 첫 단계에서 갤럭시 탭 크롬이 **MP4 녹화를 바로 지원하는지 테스트**. 지원하지 않으면 WebM 녹화 → 브라우저 안에서 MP4 변환으로 대체 (느려질 수 있음)
- **영상 크기 줄이기** (업로드·용량 대비)
  - 해상도 720p, 비트레이트 낮게 → 2~3분 영상 약 15~30MB 목표
  - Supabase 무료 요금제 기준 저장 공간 1GB, 파일 하나 최대 50MB → 한 반(6~8명) 한 수업 약 200MB 안팎이라 충분, 대신 **자동 삭제**로 쌓이지 않게
  - 50MB 넘으면 화질을 한 단계 낮춰 다시 만들기
- 화면: 전자칠판·태블릿 가로 비율, 큰 버튼, 터치 기준

## 9. 개인정보
- 서버에 올라가는 학생 영상은 **완성 MP4 하나뿐**, 촬영 원본은 태블릿 안에만
- 제출 영상은 **비공개 버킷** + 교사만 열람 (학생끼리, 방 코드만 아는 사람은 볼 수 없음)
- 보관 기간 지나면 자동 삭제, 방을 지우면 템플릿·명단·제출 영상 모두 삭제
- 여는 영상에 유치원생 얼굴이 나오면 비공개 저장 + 수업 뒤 삭제 안내
- 학교 개인정보 지침에 따라 촬영·저장 동의 여부 확인 안내 문구 (교사 모드 첫 방 만들기 때 한 번)

## 10. 만드는 순서
1. **MP4 녹화 테스트** (갤럭시 탭) + 720p 크기 확인 ← 가장 먼저
2. 방·입장·명단·템플릿 편집 뼈대
3. 카드 보기 → 촬영 모드 → 사진함 (IndexedDB)
4. 연결하기(수준별) + 녹음 + 단어 자막
5. 미리보기 재생기 + 움직임 효과 + 엔딩 크레딧
6. MP4 만들기 → **선생님께 제출 + 제출함(연속 재생·ZIP)**
7. 얼굴 쏙, 기본 템플릿 추가, 디자인 다듬기
